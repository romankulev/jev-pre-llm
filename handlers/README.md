# handlers/ — как добавить интент

Каждый файл `*.py` здесь — один интент (файлы на `_` игнорируются).
Копируй `_template.py`.

Обязательно: `HANDLER_ID` (= имя файла), `PATTERNS`, `CRITERIA`,
`run(text, ctx) -> str`. Необязательно: `REWRITE`.

Главное правило `CRITERIA`: отличие от соседей, не общее описание.
Хендлер с именованной сущностью (человек, чат, файл) проверяет извлечение
внутри `run` и падает в `ValueError` при промахе — ход уходит в LLM.
